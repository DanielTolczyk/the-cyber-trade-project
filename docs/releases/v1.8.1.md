## What's New in v1.8.1

### 1. Ecosystem Frontend Security Hardening
* **Client-Side Logbook PIN Security:** Eliminated plaintext PIN storage in LocalStorage (`logbook`). The vault now dynamically authenticates user PINs in volatile memory via PBKDF2 (100,000 rounds SHA-256) and authenticated AES-256-GCM verification, preventing local inspection and shared-terminal key extraction.
* **DOM XSS Sanitization:** Implemented a centralized `escapeHTML()` sanitization engine across all dynamic UI template renderers and ledger views in `logbook` and `estimator`.
* **Content Security Policy (CSP) Directives:** Enforced strict `<meta http-equiv="Content-Security-Policy">` directives across the Documentation Portal (`_layouts/default.html`) and Universal Digital Logbook (`logbook/public/index.html`).
* **Strict Schema File Import Gate:** Integrated defensive payload schema verification for all `.json` vault imports and QR payload scans, rejecting malformed data structures before persistence to IndexedDB.
* **Tabnabbing Protection:** Standardized `rel="noopener noreferrer"` across all external hyperlinks across the ecosystem.

### 2. Hybrid Multi-Craft Roles & Startup Generalist Specifications
* **Dedicated Practical Guide (\`docs/startup-and-hybrid-roles-guide.md\`):** Published comprehensive operational guidance for hybrid roles (DevSecOps, Platform Security) and solo startup practitioners. Details task-based NIST NICE hour allocations, Bilateral Inter-Guild Articulation Accords under the Digital Infrastructure Trades Council (DITC), and accelerated multi-domain runtime accumulation.
* **Fractional Master of Record (vMoR) Retainers:** Standardized startup safe harbors allowing small teams to retain Fractional Masters of Record for quarterly baseline sign-offs and apprentice supervision without enterprise payroll overhead.
* **FAQ Expansion (FAQ 37 - 38):** Added detailed explainers covering DevSecOps multi-domain allocations (Domain 1 + Domain 3), expanded 3:1 supervisory ratios, Modality B Git commit signing, and Hour-Bank benefit portability during startup layoffs.

### 3. Automated Release Engine & Quality Gate Overhaul
* **Curated Release Notes Pipeline (\`scripts/release.py\`):** Overhauled release automation to read structured, domain-specific release notes directly from \`docs/releases/\`, permanently eliminating raw commit hash dumps and generic fallback stubs.
* **Semantic Release Typing:** Upgraded release commit and PR formatting to enforce semantic typing (\`feat(release)\`, \`fix(release)\`, \`docs(release)\`) and removed redundant verification blocks from release bodies.
* **Historical Release Note Restoration:** Updated published GitHub release notes for \`v1.8.0\` and \`v1.7.2\` to match the ecosystem gold standard.

### 4. Portal Architecture & Pillar Core Mandates
* **Streamlined Pillar Core Mandates:** Standardized clear, distinct \`**Core Mandate:**\` callouts across all 7 foundational pillars, replacing repetitive axiom prefixes and assigning tailored mandates to Pillar IV (Licensure & Journeyman Standard) and Pillar VI (Craft Guilds & Labor Trusts).
* **Social Preview & Title Deduplication:** Resolved duplicate document titles on root index pages and added complete Open Graph / Twitter Card metadata.
